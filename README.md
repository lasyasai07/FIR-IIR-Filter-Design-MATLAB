# FIR & IIR Digital Filter Design Using MATLAB

This  focuses on the design and analysis of FIR (Finite Impulse Response) and IIR (Infinite Impulse Response) digital filters using MATLAB.

The frequency responses of the filters are analyzed and compared.

## 🎯 Objectives

* Understand FIR and IIR digital filters
* Design a low-pass FIR filter
* Design a low-pass IIR filter
* Analyze magnitude and phase responses
* Compare FIR and IIR filter characteristics

## 🧠 Concepts Used

* Digital Signal Processing
* FIR Filters
* IIR Filters
* Butterworth Filter
* Frequency Response
* Magnitude Response
* Phase Response
* MATLAB

## 🔄 FIR Filter

FIR filters are non-recursive digital filters whose output depends on present and previous input samples.

## 🔄 IIR Filter

IIR filters are recursive digital filters whose output depends on present and previous input samples as well as previous output samples.

## 🛠️ Tools Used

* MATLAB
* Signal Processing Toolbox
